# MEDIALUNA
**SOBRE EL PROYECTO**

Medialuna es una página web de pastelería donde los usuarios pueden ver productos, consultar recetas, registrarse, iniciar sesión y realizar pedidos.
También cuenta con una parte para administradores, desde donde se pueden gestionar los productos, las recetas y los pedidos.
#

**TECNOLOGÍAS QUE USAMOS**

Para realizar el proyecto usamos:
- HTML
- CSS
- JavaScript
- PHP
- MySQL
  
También utilizamos XAMPP y phpMyAdmin para trabajar de manera local con la página y la base de datos.

**PARA USAR EL PRYECTO NECESITAMOS:**

Para ejecutar la página necesitás tener instalado **XAMPP**, ya que usamos Apache y MySQL.

**¿CÓMO INSTALARLO?**

1. Descargar o copiar la carpeta del proyecto dentro de `htdocs` de XAMPP.
2. Abrir XAMPP y activar **Apache** y **MySQL**.
3. Entrar a phpMyAdmin e importar el archivo de la base de datos `.sql`.
4. Una vez hecho eso, abrir el navegador y entrar a:
`http://localhost/reposteria.medialuna/`
#

**FUNCIONES PRINCIPALES**

**Para los usuarios**

- Ver los productos.
- Filtrar productos por categorías.
- Ver recetas.
- Registrarse e iniciar sesión.
- Agregar productos al carrito.
- Realizar pedidos.
- Ver el historial de pedidos.

**Para el administrador**

- Gestionar productos.
- Gestionar recetas.
- Ver los pedidos realizados.
